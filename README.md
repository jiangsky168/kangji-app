# 康迹 · 代谢健康档案 App

面向中老年患者的个人代谢健康档案工具原型项目。覆盖四高（高血压/高血糖/高血脂/高尿酸）+ 脂肪肝的检验报告归档、指标管理、AI 解读与家庭共享。
